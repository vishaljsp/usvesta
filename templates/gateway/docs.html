1. Authentication Headers

All REST API requests require merchant authentication headers:

  • X-Api-Public-Key: Your Public Key (e.g. pub_test_... or pub_live_...)
  • X-Api-Secret-Key: Your Secret Key (e.g. sec_test_... or sec_live_...)

2. Create Payment Order

Endpoint: POST /api/v1/payment/orders

Python Request Code:
import requests

headers = {
    "X-Api-Public-Key": "pub_test_your_public_key",
    "X-Api-Secret-Key": "sec_test_your_secret_key",
    "Content-Type": "application/json"
}

payload = {
    "order_id": "ORDER_100293",
    "amount": 999.00,
    "currency": "INR"
}

response = requests.post("http://127.0.0.1:8000/api/v1/payment/orders", json=payload, headers=headers)
print(response.json())
Node.js Request Code:
const axios = require('axios');

axios.post('http://127.0.0.1:8000/api/v1/payment/orders', {
    order_id: 'ORDER_100293',
    amount: 999.00,
    currency: 'INR'
}, {
    headers: {
        'X-Api-Public-Key': 'pub_test_your_public_key',
        'X-Api-Secret-Key': 'sec_test_your_secret_key'
    }
}).then(res => console.log(res.data));

3. Webhook HMAC SHA-256 Verification Guide

When a payment succeeds, our engine POSTs payload to your Webhook Endpoint. Verify signature using your webhook secret key (whsec_...):

Python Signature Verification:
import hmac
import hashlib

def verify_webhook_signature(raw_body_bytes, signature_header, secret_key):
    expected = hmac.new(secret_key.encode('utf-8'), raw_body_bytes, hashlib.sha256).hexdigest()
    return hmac.compare_digest(expected, signature_header)
PHP Signature Verification:
<?php
$payload = file_get_contents('php://input');
$signature = $_SERVER['HTTP_X_GATEWAY_SIGNATURE'];
$secret = 'whsec_your_webhook_secret';

$expected = hash_hmac('sha256', $payload, $secret);

if (hash_equals($expected, $signature)) {
    // Valid Webhook Notification
    http_response_code(200);
}
?>
